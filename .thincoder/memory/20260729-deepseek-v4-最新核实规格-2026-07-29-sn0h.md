经 api-docs.deepseek.com 官方文档核实（2026-07-29）：

DeepSeek V4 系列：
- 模型名: deepseek-v4-pro / deepseek-v4-flash
- 上下文: Pro 1M, **Flash 1M**（Flash 已从 256K 升级到 1M）
- 最大输出: 均 384K
- 思考: thinking.type 字段 enabled/disabled，**Flash 也支持思考模式**（文档："支持非思考与思考模式（默认）"）
- reasoning_effort: **现在文档 schema 把它放在 thinking 对象内部**（thinking.reasoning_effort），值 high/max（默认 high，agent 类请求自动 max）。low/medium→high, xhigh→max。但 curl 示例仍作为顶层字段发送，兼容性暂无问题。
- 续写: prefix completion（/beta 端点），reasoning_content 必须回传
- 缓存: 前缀缓存，system prompt 逐字节稳定即命中；新增「上下文硬盘缓存」独立功能
- 价格: Flash 1元/2元(输入/输出百万tokens)，缓存命中 0.02元；Pro 3元/6元，缓存命中 0.025元；峰谷分时计费已上线（谷时算力费直降约60%）
- 并发限制: Flash 2500, Pro 500
- 新增参数: user_id（KVCache隔离+调度隔离，max 512 chars，charset [a-zA-Z0-9\-_]）
- 新增 finish_reason: insufficient_system_resource（系统推理资源不足）
- 新增 usage 字段: prompt_cache_hit_tokens, prompt_cache_miss_tokens, completion_tokens_details.reasoning_tokens
- 新增 tools strict 模式（Beta）
- frequency_penalty / presence_penalty 已 deprecated
- 旧接口 deepseek-chat / deepseek-reasoner 将于 2026-07-24 停止服务
